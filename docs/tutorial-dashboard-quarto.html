• Tutorial: crear un dashboard en R con Quarto (RStudio)

Este tutorial está pensado para que lo sigan paso a paso dentro de RStudio y terminen con un dashboard interactivo funcionando en el navegador.

Quarto permite convertir un documento .qmd (que mezcla texto, código R y resultados) en un dashboard: una página web con tarjetas (cards), gráficos, tablas y “value boxes”, organizada en filas y columnas. No requiere Shiny ni un servidor: el resultado es un archivo HTML que se puede abrir en cualquier navegador o publicar en internet.

  1. R instalado (versión 4.x recomendada).

  2. RStudio (versión 2023.09 “Desktop Marbled Salamander” o posterior; ya incluye Quarto integrado — no hace falta instalarlo aparte).

  3. Verificar que Quarto está disponible: en la consola de RStudio ejecutar:

    quarto::quarto_version()

    Si el paquete quarto no está instalado:

    install.packages("quarto")

  4. Paquetes de R que usaremos en el ejemplo:

    install.packages(c("palmerpenguins", "dplyr", "ggplot2", "plotly", "DT", "bslib"))
  1. En RStudio: File → New File → Quarto Document…
  2. En el cuadro de diálogo se puede elegir “Dashboard” directamente (en versiones recientes de RStudio aparece como plantilla), o simplemente crear un documento .qmd en blanco y pegar el YAML que se explica abajo.
  3. Guardar el archivo, por ejemplo, como mi_dashboard.qmd.

Todo dashboard comienza con un encabezado YAML donde el format es dashboard:

---
title: "Mi primer dashboard"
format: dashboard
---

A partir de ahí, la estructura visual se define con títulos Markdown, no con código:

  • ## (nivel 2) crea filas o columnas (secciones principales).
  • ### (nivel 3, o los bloques de código en sí) crean tarjetas (cards) dentro de esas filas/columnas.
  • El atributo orientation: rows o orientation: columns en el YAML define si los ## se apilan como filas o columnas por defecto.
  • Se puede fijar el tamaño con {height=30%} o {width=60%} junto al título.
Elemento Cómo se hace
Card con un gráfico Un bloque de código R con #| title: "Nombre"
Value box (número destacado) Bloque de código con #| content: valuebox
Tabla interactiva Paquete DT dentro de un bloque de código
Pestañas (tabset) ## {.tabset}
Barra lateral ## {.sidebar}
Múltiples páginas Usar # Nombre de página (nivel 1)

Vamos a construir un dashboard con el dataset palmerpenguins (mediciones de pingüinos), muy usado para enseñar.

Paso 1 — YAML y configuración inicial 
---
title: "Pingüinos de Palmer"
format:
  dashboard:
    orientation: columns
    theme: cosmo
---
Paso 2 — Cargar datos (bloque de configuración, oculto) 
```{r}
#| label: setup
#| include: false

library(palmerpenguins)
library(dplyr)
library(ggplot2)
library(plotly)
library(DT)

datos <- penguins |> filter(!is.na(sex))
```
Paso 3 — Fila de value boxes con estadísticas clave 
## Row {height=20%}

```{r}
#| content: valuebox
#| title: "Total de pingüinos"
list(icon = "clipboard-data", color = "primary", value = nrow(datos))
```

```{r}
#| content: valuebox
#| title: "Especies"
list(icon = "bar-chart", color = "info", value = length(unique(datos$species)))
```

```{r}
#| content: valuebox
#| title: "Peso promedio (g)"
list(icon = "graph-up", color = "success",
     value = round(mean(datos$body_mass_g), 0))
```
Paso 4 — Fila con gráficos interactivos 
## Row {height=80%}

### Column {width=60%}

```{r}
#| title: "Largo vs profundidad del pico"
p <- ggplot(datos, aes(x = bill_length_mm, y = bill_depth_mm, color = species)) +
  geom_point(size = 2, alpha = 0.7) +
  labs(x = "Largo del pico (mm)", y = "Profundidad del pico (mm)") +
  theme_minimal()
ggplotly(p)
```

### Column {width=40%}

```{r}
#| title: "Cantidad por especie"
ggplot(datos, aes(x = species, fill = species)) +
  geom_bar() +
  theme_minimal() +
  theme(legend.position = "none")
```
Paso 5 (opcional) — Segunda página con una tabla 
# Datos

```{r}
#| title: "Tabla completa"
datatable(datos, options = list(pageLength = 10))
```

Nota: al copiar estos bloques en RStudio, quita las llaves dobles {r} y déjalas como {r} (aquí se duplicaron solo para que se muestren como texto en este tutorial).

En RStudio, con el archivo .qmd abierto:

  • Hacer clic en el botón Render (arriba del editor), o

  • Ejecutar en la consola:

    quarto::quarto_render("mi_dashboard.qmd")

Esto genera un archivo mi_dashboard.html que se abre automáticamente en el visor de RStudio o en el navegador.

Una vez que funciona localmente, se puede compartir de varias formas:

  • Quarto Pub (gratis, un comando): quarto publish quarto-pub mi_dashboard.qmd
  • GitHub Pages: subiendo el HTML generado a un repositorio.
  • Posit Connect (si la institución tiene servidor propio).
  1. Cambiar el dataset por uno propio (por ejemplo, un CSV cargado con read.csv()).
  2. Agregar una cuarta value box con otra estadística (por ejemplo, la isla con más avistamientos).
  3. Convertir uno de los gráficos estáticos en interactivo con ggplotly().
  4. Agregar una barra lateral (## {.sidebar}) con un texto explicativo del dataset.
  5. Crear una segunda página con una tabla filtrable usando DT::datatable().
